## 阅读顺序建议

- **产品 / 业务**：01 → 06
- **新接手的工程师**：01 → 03 → 02 → 04
- **第三方接入**：05 → 03
- **算法 / AI 调优**：02 → 06

## 维护原则

1. **文档跟着代码改**：改 controller 就更新 05；改 EditorScreen 就更新 04
2. **路径用 file:line 引用源码**：让读者一跳就能找到实现
3. **不写"未来可能要"**：路线图里写的项必须有人愿意做或已纳入排期，否则删掉
4. **决策记到 06 末尾**：避免同一个问题反复讨论
